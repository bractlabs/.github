# Contributing to the bractlabs Community

Thank you for helping us improve the public playable builds and the conversation around Bract.

## What Is Available

Bract Racer's open-source release is planned, but its public source repository, license and code contribution workflow have not been announced yet. For now, contributions are bug reports, questions, feedback and documentation corrections in the public community repositories.

Bract Engine is not open-source. Engine source access is governed by corporate agreements; do not submit or request proprietary engine code in a public issue, discussion or pull request.

## Bug Reports

Search existing reports first. Include the public build URL, browser and version, operating system, GPU if known, expected behavior, actual behavior and a minimal set of reproduction steps. Screenshots are useful when they do not contain personal information.

Remove tokens, cookies, credentials, personal information and proprietary code from logs before posting. If a report concerns a security weakness, follow SECURITY.md instead of opening a public issue.

## Questions and Ideas

Use Discussions in the community repository for questions, ideas and experiments. Use Issues for reproducible bugs. Suggestions are welcome, but do not represent a delivery commitment or a promised release date.

## Pull Requests

Keep public community documentation changes small and focused. Explain what changes and why. Do not add a software license, change source-access claims or include game or engine code without maintainer approval.

Game code contribution instructions will be published with the future open-source game release.

# Procedural Worlds. Real Games. WebGPU.

We build **Bract**, a WebGPU-native engine for procedural worlds, and games that put it to work. From individual GPU-grown fur strands to a sun 149.6 billion metres away, our development builds bring close-up detail and planetary scale into the same world.

[Website](https://bractlabs.com) · [Play Racer](https://bractlabs.com/games/racer/) · [Engine](https://bractlabs.com/engine/) · [Showcases](https://bractlabs.com/showcases/)

[![Bract Racer on the mountain roads of Summit Pass in the snow](https://bractlabs.com/showcases/summit-pass-snow.jpg)](https://bractlabs.com/games/racer/)

## Bract Racer

An early, unpolished browser racing game with AI rivals, changing weather, procedural cars, visible damage and virtual-surface fur. Racer already uses Bract's planet-scale precision: mesh circuits on a planet with a 6,371,000-metre radius, illuminated by a sun one astronomical unit away. The advanced terrain system is not yet integrated into the game.

**Game source: open-source release planned soon.** We will announce the repository, license and contribution instructions when the release is ready. The playable build is available now; it is not a public source release.

## Bract Engine

GPU-driven rendering, procedural modeling, Nature simulation, effects, virtual surfaces, lighting and large-world precision, built for WebGPU.

**Engine source: shared under corporate agreements, not open-source.** The planned Racer source release does not grant access to or a license for Bract Engine source. For corporate access, contact [info@bractlabs.com](mailto:info@bractlabs.com) or visit [Partners](https://bractlabs.com/partners/).

Bract is pre-release software, not production-ready; APIs, features and performance are still changing.
